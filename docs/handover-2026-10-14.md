## Built and verified
- **Portal:** React/TypeScript/Vite, Cognito managed login with MFA, code + PKCE,
  in-memory tokens and logout. One portal with role-specific views.
- **Employees:** create tickets and see only their own. Priority comes from domain
  rules; callback phone comes from the trusted profile, not browser input.
- **Engineers:** see all tickets, claim unassigned human escalations, and record
  completed/failed outcomes with notes only on tickets assigned to themselves.
  Assignment/outcome safeguards pass automated tests; a real agent escalation and
  end-to-end human handoff have not yet been exercised.
- **Backend:** FastAPI, access-token verification plus Cognito userInfo check,
  active database profile and Cognito-group role intersection, scoped reads,
  idempotent creation, version checks and atomic audit/outbox writes.
- **Persistence:** RDS PostgreSQL 17, database/schema `sahayak`, SQLAlchemy + psycopg
  + Alembic. Current migration `0003_dispatch`. Restricted runtime logins
  `sahayak_portal` and `sahayak_dispatch`; administrator used only for setup.
  Verified TLS. POC public RDS access restricted to the laptop IP; update the /32
  if that IP changes. PostgreSQL provider portability remains a requirement.
- **Dispatch:** due outbox polling, fenced leases, bounded retries, SQS Standard
  plus DLQ after five receives, and receipt-before-message-deletion deduplication.
  A deterministic local LangGraph preflight checks database authority, state,
  schedule generation, due time and trusted contact. It saves an operational
  receipt without changing ticket status or creating a call attempt.
- **Live acceptance:** user confirmed login/logout, employee creation, engineer
  listing, worker setup and `published` followed by `ready_calls_disabled`.
  Latest reported snapshot: 0 due, 1 future, 0 exhausted, 1 published,
  1 ready_calls_disabled receipt, no attention items. This is a snapshot, not a
  continuously monitored state. Future work correctly waits until due.
- **Tests:** latest 75 Python tests + 10 subtests pass; 20 browser tests previously
  passed; 24 worker and 22 portal embedded PostgreSQL checks passed. Embedded tests
  do not prove multi-session races. No voice, model-quality or full recovery/DLQ
  live acceptance is claimed.
